# Heir of Death

A 1v1 First-Person Tactical Action Shooter built in **Unity (C#)** using **Unity Netcode for GameObjects** and **Microsoft PlayFab**. Players face off over a local network (**LAN**) in fast-paced, round-based duels using firearms and supernatural tactical abilities.

---

## ✨ About the Game

* **1v1 LAN Duels:** Play with a friend on the same local network (Host & Client). Pick your character in the lobby, lock in, and compete in first-to-10-rounds matches.
* **Supernatural Tactical Powers (`Q`):** Choose from four distinct abilities to outsmart your opponent:
  * **Teleportation:** Aim and blink across the map to reposition quickly.
  * **Invisibility:** Become temporarily invisible to sneak past enemy lines.
  * **X-Ray Vision:** Spot your opponent through walls and obstacles.
  * **Stealth (Quiet Movement):** Mute your footsteps to move silently.
* **Fluid Movement & Weapons:** Switch between a rifle and a pistol (`1` / `2`), sprint, crouch, slide across terrain (`Left Alt` / `Left Ctrl`), and listen for surface-based footsteps (grass, gravel, etc.) to track enemy movement.
* **Accounts & Leaderboard (PlayFab):** Includes user registration, login, player leveling, and a global Top 10 win leaderboard powered by PlayFab.

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| **W, A, S, D** | Move |
| **Space** | Jump |
| **Left Shift** | Sprint |
| **Left Ctrl / Left Alt** | Crouch / Slide |
| **1 / 2** | Switch Weapon (Rifle / Pistol) |
| **Left Click / R** | Shoot / Reload |
| **Q** | Use Tactical Power |
| **Esc** | Pause Menu |

---

## 🚀 How to Play (LAN)

1. Both players must be connected to the **same local network (LAN / Wi-Fi)**.
2. Log in to your account (or register a new one).
3. **Player 1** clicks **Host** — their local IPv4 address will be displayed on the character selection screen.
4. **Player 2** enters the Host's IP address and clicks **Client** to join.
5. Select your characters, click **Lock In**, and the match begins.
